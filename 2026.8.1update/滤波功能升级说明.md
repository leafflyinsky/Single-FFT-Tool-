# 🎉 滤波功能升级完成！

## ✅ 已实现功能

### 📊 6种滤波方法

| 序号 | 滤波方法 | 功能说明 | 核心参数 |
|-----|---------|---------|---------|
| 1 | **去趋势项** | 去除信号中的趋势成分 | 类型：去均值/去线性/去二次项 |
| 2 | **Hampel滤波** | 异常值检测与替换 | 窗口大小、阈值倍数 |
| 3 | **高通滤波** | 滤除低频成分 | 截止频率、滤波器阶数 |
| 4 | **带通滤波** | 保留特定频段 | 低频截止、高频截止、阶数 |
| 5 | **SG滤波** | Savitzky-Golay平滑 | 窗口大小、多项式阶数 |
| 6 | **ACG自动增益** | 自动调整信号幅度 | 目标RMS值 |

### 🎯 核心特性

✅ **自由组合** - 可同时启用多个滤波器  
✅ **顺序可调** - 拖拽调整滤波器应用顺序  
✅ **参数可调** - 每个滤波器参数完全可定制  
✅ **参数校验** - 自动检测参数合法性，防止错误  
✅ **上下对比** - 滤波前后信号直观对比显示  
✅ **数据导出** - 滤波后数据可导出CSV文件

## 🚀 使用方法

### 1️⃣ 启动工具

**Windows用户：**
```bash
# 方法1：双击启动脚本
启动工具.bat

# 方法2：命令行启动
python app.py
```

**访问地址：** http://localhost:5000

### 2️⃣ 上传数据文件

- 拖拽CSV文件到上传区域
- 或点击选择文件
- 设置采样率（默认1000Hz）

### 3️⃣ 配置滤波器

**勾选启用的滤波器** → **调整参数** → **拖动调整顺序**

#### 参数建议：

**去趋势项：**
- 去均值：信号有直流偏置时使用
- 去线性：信号有线性漂移时使用
- 去二次项：信号有二次趋势时使用

**Hampel滤波：**
- 窗口大小：5-21（奇数）
- 阈值倍数：3（推荐），越大越宽松

**高通滤波：**
- 截止频率：根据需要保留的低频设置
- 滤波器阶数：4（推荐）

**带通滤波：**
- 低频截止：根据实际需求
- 高频截止：不超过采样率/2
- 滤波器阶数：4（推荐）

**SG滤波：**
- 窗口大小：11-51（奇数）
- 多项式阶数：3（必须小于窗口大小）

**ACG自动增益：**
- 目标RMS值：1.0-10.0

### 4️⃣ 开始分析

点击 **"开始分析"** 按钮，系统将：
- 应用选定的滤波器
- 计算滤波前后的时域和频域特征
- 显示对比图表和指标表

### 5️⃣ 查看结果

**波形对比（左侧）：**
- 上方：原始信号波形
- 下方：滤波后信号波形

**频谱对比（右侧）：**
- 上方：原始信号频谱
- 下方：滤波后信号频谱

**指标对比表：**
- 显示所有分析指标的原始值、滤波后值和变化百分比

### 6️⃣ 导出数据

点击 **"导出滤波后数据 (CSV)"** 按钮，下载处理后的数据。

## ⚠️ 注意事项

### 参数校验规则

1. **高通/带通滤波：**
   - 截止频率必须小于奈奎斯特频率（采样率/2）
   - 带通滤波的低频 < 高频

2. **SG滤波：**
   - 窗口大小必须是奇数
   - 多项式阶数必须小于窗口大小

3. **Hampel滤波：**
   - 窗口大小至少为3

### 滤波器顺序建议

推荐顺序（从上到下）：
```
去趋势项 → Hampel滤波 → 带通/高通滤波 → SG滤波 → ACG自动增益
```

**原因：**
1. 先去除趋势项，避免影响后续滤波
2. 再去除异常值，防止异常值影响滤波器
3. 然后进行频域滤波
4. 最后进行平滑和增益调整

## 🔧 技术细节

### 滤波器实现

- **Hampel滤波**：滑动窗口中位数 + MAD（中位数绝对偏差）
- **高通/带通滤波**：Butterworth滤波器 + filtfilt零相位滤波
- **SG滤波**：scipy.signal.savgol_filter
- **ACG**：自动调整增益到目标RMS值

### 数据量限制

- 推荐：≤ 10,000 数据点
- 最大支持：约100,000点（可能较慢）

### 输出格式

**CSV导出：**
```
Time (s),Amplitude
0.000000,1.234567
0.001000,2.345678
...
```
