# 快速开始指南

## 第一步：安装依赖

### 方法1：使用自动脚本（推荐）
双击运行 `启动工具.bat`（Windows）或在终端运行 `./启动工具.sh`（Mac/Linux）

### 方法2：手动安装
```bash
pip install -r requirements.txt
```

## 第二步：启动服务器
```bash
python app.py
```

看到以下提示表示启动成功：
```
============================================================
振动信号分析工具已启动
请在浏览器中打开: http://localhost:5000
============================================================
```

## 第三步：打开网页
在浏览器中访问：http://localhost:5000

## 第四步：上传数据

### 测试数据
项目中已包含 `demo_data.csv` 演示文件：
- 主频：50 Hz
- 二次谐波：100 Hz
- 采样率：1000 Hz
- 数据点数：1000

### 你的数据
准备CSV文件，格式要求：
- **推荐格式**：单行，用逗号分隔
  ```
  1.23,4.56,7.89,2.34,...
  ```
- 也支持单列数据（每行一个数值）

## 第五步：设置参数并分析
1. 在网页中设置采样率（默认1000 Hz）
2. 点击"开始分析"按钮
3. 查看分析结果

## 分析结果说明

### 时域特征
| 指标 | 说明 | 典型用途 |
|------|------|----------|
| RMS | 均方根值，衡量振动强度 | 设备状态监测 |
| 峰值 | 最大振幅 | 确定振动范围 |
| 峰值因子 | 峰值/RMS，>5表示有冲击 | 轴承/齿轮故障检测 |
| 峅度 | >3表示偏离正态分布 | 早期故障检测 |

### 频域特征
| 指标 | 说明 | 应用场景 |
|------|------|----------|
| 主频 | 幅值最大的频率 | 确定振动来源 |
| 主频能量占比 | 主频附近能量占比 | 评估振动集中度 |
| 频谱中心 | 频谱的加权平均 | 特征提取 |

## 常见问题

**Q: 为什么主频检测结果不准？**
A: 检查采样率设置是否正确。根据奈奎斯特定理，采样率应≥2×信号最高频率。

**Q: 数据格式不支持？**
A: 确保CSV文件只包含数值数据，没有表头或文字说明。

**Q: 图表显示异常？**
A: 建议数据点数在100-10000之间。数据过多会自动降采样。

## 技术支持
如有问题，请检查：
1. Python版本 ≥ 3.7
2. 所有依赖包正确安装
3. CSV文件格式正确
4. 浏览器控制台无错误信息
