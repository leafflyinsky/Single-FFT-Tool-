# 编码问题修复说明

## 问题描述
在打包PyQt5应用时，如果程序路径包含中文字符，会出现以下错误：
```
UnicodeEncodeError: 'latin-1' codec can't encode characters in position 51-56: ordinal not in range(256)
```

## 解决方案
已添加自定义运行时钩子 `runtime_hook_fix_encoding.py`，该钩子会：
1. 强制使用UTF-8编码
2. 修复Qt配置文件的编码问题
3. 在PyInstaller的默认钩子之前执行

## 修改的文件
1. **runtime_hook_fix_encoding.py** - 新增编码修复钩子
2. **FFT振动分析工具.spec** - 更新spec文件，添加运行时钩子
3. **build_portable_fixed.bat** - 新的打包脚本

## 如何重新打包
运行以下命令：
```bash
pyinstaller "FFT振动分析工具.spec" --clean -y
```

或者运行打包脚本：
```bash
build_portable_fixed.bat
```

## 测试方法
将打包好的 `dist\FFT振动分析工具\` 整个文件夹复制到其他电脑，双击运行 `FFT振动分析工具.exe` 即可。

## 注意事项
- 必须保持整个文件夹完整，不要只复制exe文件
- `_internal` 目录包含所有必需的运行库文件
- 可以放在任意路径下运行，包括中文路径

## 技术细节
PyInstaller的PyQt5运行时钩子默认使用latin-1编码创建qt.conf文件，无法处理中文路径。我们的自定义钩子通过：
1. 重新配置标准输出/错误的编码为UTF-8
2. 手动创建UTF-8编码的qt.conf文件
3. 在PyQt5加载之前执行，确保优先级

这样就彻底解决了中文路径编码问题。
