# 振动信号分析工具

一个基于Web的离线振动信号分析工具，支持FFT频谱分析和多种时域/频域特征提取。

## 功能特性

### 时域分析
- **RMS (均方根值)**: 衡量振动强度
- **峰值 (Peak)**: 最大振幅
- **峰值因子 (Crest Factor)**: 峰值/RMS，反映冲击特性
- **峭度 (Kurtosis)**: 衡量信号偏离正态分布的程度
- **均值 (Mean)**: 信号的平均值
- **标准差 (Std)**: 信号的离散程度

### 频域分析
- **FFT频谱图**: 显示信号的频率成分
- **主频检测**: 自动识别振动的主要频率
- **主频能量占比**: 主频附近能量占总能量的百分比
- **频谱中心**: 频谱的加权平均频率
- **Top 5主要频率**: 列出幅值最大的5个频率成分

### 可视化
- **时域波形图**: 显示原始加速度信号
- **FFT频谱图**: 显示频率分布

## 使用方法

### 1. 准备数据文件
- CSV文件格式：数据应该在第一行，每列一个数据点，用逗号分隔
- 例如：`1.23, 4.56, 7.89, ...` (1000个数据)
- 或者每行一个数值也可以

### 2. 上传和分析
1. 拖拽CSV文件到上传区域，或点击选择文件
2. 设置正确的采样率（默认1000 Hz）
3. 点击"开始分析"按钮
4. 查看分析结果和图表

## 技术说明

### FFT分析
- 使用Hanning窗减少频谱泄漏
- 自动归一化幅值
- 只显示正频率部分（0 到 Nyquist频率）

### 主频能量占比
- 计算主频±5Hz带宽内的能量
- 与总能量比较得出占比

### 峰值因子
- 正常振动：通常在 3-5 之间
- 冲击振动：会明显增大（>5）
- 用于检测轴承故障、齿轮故障等

### 峭度
- 正态分布信号：≈ 3
- 冲击性信号：> 3
- 用于检测早期故障

## 常见问题

**Q: 上传后提示"无法从文件中解析出有效数据"**
A: 检查CSV文件格式，确保数据是数值型，没有表头或文字说明

**Q: 主频检测结果不准**
A: 检查采样率设置是否正确。采样率应至少为信号最高频率的2倍

**Q: 图表显示很慢**
A: 数据点数过多时，前端会自动降采样。建议数据点数不超过10000

**Q: 能否处理其他格式的数据**
A: 当前仅支持CSV格式。可以先用Excel或文本编辑器转换为CSV
